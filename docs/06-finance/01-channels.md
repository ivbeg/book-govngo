# Каналы финансирования

Материальная поддержка некоммерческих организаций идёт несколькими путями. В книге они не равноценны: по одним есть сумма и год, по другим — примеры, по третьим суммы нет. Канал без измерения не подмешивается к «более 500 миллиардам».

| Канал | Что сделано в книге |
| --- | --- |
| Субсидии федерального бюджета | Сумма за 2019 год и список 22 крупнейших государственных получателей. [Глава](./02-federal.md) |
| Субсидии бюджетов субъектов | Сумма за 2019 год и таблица субъектов. [Глава](./03-regional.md) |
| Контракты по 44-ФЗ и 223-ФЗ | Примеры контрактов. Суммы по сектору нет. [Глава](./04-contracts.md) |
| Пожертвования государственных компаний | Один разобранный случай, Российский научный фонд и «Роснефтегаз». [Глава](./05-donations.md) |
| Гранты, которые фонды раздают дальше | Не измерены. Фонд президентских грантов учтён как получатель субсидии, не как раздатчик. [Глава](./06-unmeasured.md) |
| Имущественный взнос Российской Федерации | Назван. Отдельного учёта нет. Один эпизод упомянут рядом с пожертвованием РНФ |
| Средства под управлением организаций, учреждённых Правительством, в том числе ВЭБ.РФ | Не измерены |

Базовые оценки ниже построены на субсидиях. Код вида расходов и казначейское сопровождение объяснены в главе о федеральном бюджете. Словарь кодов — в [приложении](../09-appendices/02-kvr.md).
