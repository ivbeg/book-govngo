# В сравнении с негосударственными НКО

:::warning[Черновик]
Построчная сверка открытости крупнейших получателей не проведена. Ниже то, что уже следует из норм и примеров книги, и чек-лист для такой сверки. Оценки «открыта / закрыта» по организациям не проставлены.
:::


Негосударственная НКО в этой книге — организация без государственного учредителя и без преобладающего бюджетного финансирования. По одному только ЕГРЮЛ граница часто не видна. Способы провести её описаны в главе [методов учёта](../03-identification/01-methods.md).

## Что уже видно без обхода сайтов

Деньги распределены не как поддержка независимого сектора. Преобладающая доля субсидий приходится на государственные НКО. Фонд президентских грантов сам получает федеральную субсидию и раздаёт её организациям гражданского общества. Без его 8,01 миллиарда рублей на остальные организации из списка крупнейших получателей всё равно приходится 57% федеральных субсидий НКО. Считается это в главе о [федеральном бюджете](../06-finance/02-federal.md).

Льгота социально ориентированной НКО задумана для организаций вне государства. В реестр вошли и государственные организации с крупными субсидиями. Список и коридор сумм — в главе [о СОНКО](../05-regulation/07-sonko.md). Статус в реестре не отличает одну группу от другой.

Открытость не следует из размера получения. Российский научный фонд публикует архив документов. Про Национальный выставочный оператор, получателя крупного контракта, рукопись не находит сайта. Контракт назван в главе [о контрактах](../06-finance/04-contracts.md). Слабость доказательства по сайту оговорена в [обзоре открытости](./01-overview.md).

Стандарты открытости некоммерческого сектора на государственные НКО целиком не распространены. Это вывод [карточек решений](../08-policy/01-decisions.md), а не результат обхода сайтов.

## Чек-лист

Для организации из списка получателей отметить пять пунктов. Ответ «не проверялось» допустим и честнее, чем догадка.

- Есть ли официальный сайт.
- Опубликован ли годовой отчёт.
- Опубликованы ли сведения о доходах руководства. Для организаций, созданных федеральным законом, это требование [указа № 613](../05-regulation/06-anticorruption.md). Для остальных такого требования рукопись не находит.
- Видны ли закупки и контракты. Собственные закупки НКО из контрактной системы выпадают, см. главу [«Закупки»](../05-regulation/04-procurement.md).
- Видны ли учредители в ЕГРЮЛ. Пробелы реестра описаны в главе [«Регистрация»](../05-regulation/03-registration.md).

Имеет смысл пройти чек-лист по [22 получателям федерального бюджета](../09-appendices/03-federal-top-2019.md) и по региональным случаям из главы о [бюджетах субъектов](../06-finance/03-regional.md): Московский фонд реновации, Фонд жилищного строительства ЯНАО, Конгрессно-выставочное бюро Москвы.
