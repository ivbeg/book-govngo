# В сравнении с бюджетными учреждениями

:::warning[Черновик]
Таблица ниже сводит режимы, которые книга уже описала. Это не аудит конкретного учреждения и конкретной НКО, кроме примера Аналитического центра.
:::


Бюджетное учреждение раскрывает сведения на [bus.gov.ru](https://bus.gov.ru/) и закупает по 44-ФЗ. Государственная НКО, созданная вместо учреждения, из обоих режимов выходит.

Показательный переход — реорганизация ФГБУ «Аналитический центр при Правительстве Российской Федерации» в АНО. Закупки учреждения публиковались, контракты АНО из 44-ФЗ и 223-ФЗ вышли. Документы и даты — в главе [по учредителю](../04-classification/02-by-founder.md).

| Что задаёт норма | Бюджетное учреждение | Государственная НКО |
| --- | --- | --- |
| Сведения на bus.gov.ru | Режим раскрытия для государственных и муниципальных учреждений есть | Отдельного режима книга не находит |
| 44-ФЗ | Распространяется | Не распространяется |
| 223-ФЗ | Распространяется на бюджетные учреждения | Не распространяется: закон говорит о хозяйственных обществах, не об НКО |
| Ограничения оплаты и режима работы | Есть | Нет: НКО вправе задать сетку и режим без тех ограничений, которые есть у учреждения |
| Обязанность раскрытия по образцу акционерного общества | К учреждению это требование книга не относит | Нет |
| Казначейское сопровождение субсидии с кодом 632 | Контроль платежей казначейством | То же. Публичного раскрытия сопровождение не даёт |

Последняя строка отделяет контроль от открытости. Определение сопровождения — в главе о [федеральном бюджете](../06-finance/02-federal.md). Юридическая причина строки про 223-ФЗ — в главе [«Закупки»](../05-regulation/04-procurement.md).

## Источники

- [bus.gov.ru](https://bus.gov.ru/).
- 44-ФЗ и 223-ФЗ.
- Распоряжение Правительства РФ от 27.12.2014 № 2751-р — реорганизация Аналитического центра.
