# План книги

Каркас частей собран из прежней рукописи. Ниже статус после переноса. «Черновик» значит: глава есть, обещанного измерения нет.

| Часть | Статус | Чего не хватает |
| --- | --- | --- |
| О книге | Собрано | Дата выгрузки таблиц так и не проставлена |
| Граница понятия | Собрано | Госкорпорации вынесены из классификации намеренно |
| Как узнать | Собрано | Четвёртый и пятый способы не дают отдельного числа |
| Классификация по учредителю и мандату | Собрано | Оси пересекаются, это названо |
| Классификация по функции | Черновик | Нет численности и доли денег по ролям |
| Регулирование | Собрано | Три выписки ЕГРЮЛ в главу о регистрации не вставлены |
| Федеральные и региональные субсидии | Собрано | Расхождения 152 / 152,5 и 2,2% / 1,34% оставлены обеими цифрами |
| Контракты и пожертвования | Примеры | Нет суммы по сектору |
| Каналы без измерения | Граница | Гранты на выходе, имущественный взнос, ВЭБ.РФ |
| Открытость | Черновик | Чек-лист не пройден по 22 получателям и по региональным фондам |
| Карточки решений | Собрано | Это прежние четыре предложения, не новый законопроект |
| Федеральный ряд 2009–2019 | Черновик | Есть только 2012 и 2019 |

Не входит в текущий объём: перевод, PDF, перенос на Docusaurus, обновление цифр после 2020 года, восстановление годового ряда без источника.
