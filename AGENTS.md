# Государственные НКО — книга на Docusaurus

Книга о государственных и подведомственных некоммерческих организациях в России: как их отличить от соседних форм, как посчитать, какие нормы на них не действуют, откуда берутся деньги и чего не хватает в открытости.

- Принципы: `.cursor/rules/book-principles.mdc`
- Шаблоны глав: `.cursor/rules/chapter-writing.mdc`
- Статус частей: `PLAN.md`
- Старые пути: `stable-paths.md`

Текст лежит в `docs/`. Части и главы упорядочены числовыми префиксами папок и файлов. Docusaurus сам снимает префикс с адреса: `docs/04-classification/02-by-founder.md` становится `/classification/by-founder/`. Боковое меню собирается из папок (`sidebars.ts`). Оглавление `SUMMARY.md` больше не ведётся.

Цифры таблиц лежат в `data/`. После правки CSV заново собрать приложения:

```bash
python3 scripts/render-tables.py
```

```bash
npm start
npm run build
```

Сборка пишет сайт в `build/`. Адрес на GitHub Pages — `/book-govngo/`. Этот префикс стоит в `docusaurus.config.ts` и в файлах `static/*.html`.

Окно данных — 2018–2020. Новые суммы после 2020 года не добавлять без источника и даты. Годы федерального ряда между 2012 и 2019 не заполнять.
