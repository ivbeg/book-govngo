# Государственные НКО и их открытость

Книга Ивана Бегтина о государственных и подведомственных некоммерческих организациях в России. Цифры относятся к 2018–2020 годам.

Рукопись лежит в `docs/`. Порядок частей задают числовые префиксы папок. В адресе страницы префикса нет: `docs/06-finance/02-federal.md` открывается как `/finance/federal/`. Таблицы сумм лежат в `data/`.

```bash
npm install
python3 scripts/render-tables.py
npm start
npm run build
```

Сборка пишет сайт в `build/`. Публикация на GitHub Pages настроена в `.github/workflows/deploy.yml`. В настройках репозитория источник Pages должен быть GitHub Actions.

Как устроена книга и чего в ней ещё нет: `AGENTS.md` и `PLAN.md`.
